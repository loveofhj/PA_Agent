# FAKE 데이터로 100개 작업 검증

LT2 FRT 도어트림 LH 100개의 작업계획과 S7 검사 데이터를 검증합니다. 모든 데이터는 시연용입니다.

## 실행

저장소 루트에서 Python 3.10 이상으로 실행합니다. 별도 패키지나 Ollama가 필요하지 않습니다.

```sh
python -m scripts.fake100
python -m scripts.fake100 --report fake100-report.json
```

스크립트는 임시 저장소에 Mock HTTP 서버를 열고, 결과를 표준 출력에 JSON으로 표시합니다. 선택한 리포트 경로에는 새 파일을 생성하며 종료 시 임시 저장소를 정리합니다. 기존 Compose 서비스 및 데이터와 독립적으로 동작합니다.

## 검증 절차와 기대 결과

| 순서 | 검증 | 기대 결과 |
|---|---|---|
| 1 | LH 100개 작업지시 | S1~S8, LOT 10개 × 10개, 배치 미리보기 |
| 2 | 단품 Mock 정상·복구·인터록 불일치·최종 NG | 정상·복구는 완료 및 S8 확인. 인터록 불일치는 호출 없이 보류. 최종 NG는 보류 및 S8 차단 |
| 3 | LOT별 FAKE 제품과 S7 에피소드 생성 | 총 100건, 최초 합격 95건, 모의 재작업 후 합격 3건, 최종 NG 2건 |
| 4 | 데이터 검사 | 검사값과 라벨이 일치하는 데이터 100건 모두 A등급. 제품 NG 2건도 A등급 가능 |
| 5 | 분할 및 카탈로그 등록 | 지그와 세션을 LOT 단위로 묶어 학습 70·검증 20·테스트 10건. fake100 v1, Sim, S7 조회 |
| 6 | 차단 시험 | 배치 실행, 동일 지그·세션 교차 분할, 필수 모달 누락·라벨 불일치 C등급 승격은 HTTP 400 |

시나리오에서 재작업 후 합격 제품은 010·045·080번이며, 최종 NG는 084·099번입니다. 나머지는 최초 합격입니다. 이 분포는 테스트 입력이며 공정 실적이나 모델 성능 지표로 사용하지 않습니다. LOT별 집계는 리포트에 포함됩니다. 100건은 S7 합성 검사 기록이며, S1~S8의 실행과 복구는 단품 시나리오에서 검증합니다.

## 운영 화면으로 확인

기존 앱에서 **작업 관리** → 100개 계획 미리보기로 LOT 및 공정 흐름을 확인합니다. 새 1개 작업을 만들어 정상 또는 복구 Mock을 실행하면 활동 기록에서 결과를 볼 수 있습니다. **데이터 수집**에서 Mock 에피소드를 하나 만든 뒤 데이터셋 화면에서 등록하면 품질 검사 및 카탈로그 흐름을 화면으로 확인할 수 있습니다. 자동 실행의 100건 집계는 별도의 JSON 리포트에서 확인합니다.
